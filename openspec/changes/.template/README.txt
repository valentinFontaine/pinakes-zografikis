OpenSpec Change Template
=======================

This directory serves as a template for new OpenSpec changes.

To create a new change:
  openspec new change <name>

Required artifacts:
  - proposal.md    (WHY - motivation and impact)
  - design.md      (HOW - technical approach)
  - specs/         (WHAT - requirements per capability)
    └── <capability>/
        └── spec.md
  - tasks.md       (implementation checklist)

See init-open-spec change for a complete example.
